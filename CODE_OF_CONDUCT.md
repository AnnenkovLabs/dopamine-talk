# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in **Dopamine Talk** a respectful, harassment-free experience for everyone, regardless of background, identity, language, or level of experience.

## Our Standards

Examples of behavior that helps build a great open-source community:

- Giving direct, constructive feedback focused on ideas, prompts, and code rather than people.
- Respecting differing perspectives and native language nuances across editions.
- Showing empathy toward other contributors and users.

Examples of unacceptable behavior:

- Harassment, personal attacks, slurs, or trolling.
- Publishing private information without explicit permission.
- Any conduct that would reasonably be considered inappropriate in a professional open-source community.

## Enforcement

Maintainers may edit, remove, or reject comments, commits, issues, or pull requests that violate this Code of Conduct, and may ban repeat or severe offenders.

Report issues to the maintainers via GitHub Issues or [AnnenkovLabs](https://github.com/AnnenkovLabs).
